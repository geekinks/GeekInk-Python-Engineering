# Code Review Checklist

- [ ] The code runs and the reviewer can reproduce the result.
- [ ] Names, structure, and comments explain intent.
- [ ] Inputs and likely error cases are handled.
- [ ] Tests or manual checks cover key behaviour.
- [ ] Documentation gives setup, run, and test steps.
- [ ] No secrets, personal data, or virtual environments are committed.
- [ ] Feedback identifies an effect and a specific improvement.
