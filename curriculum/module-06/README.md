# Module 06: Database and Backend Engineering

**Days 51--60 | Intermediate**

---

## Overview

This module introduces relational databases and backend web development. You will learn to design database schemas, write SQL queries, integrate databases with Python, and build REST APIs using FastAPI. Flask is introduced as an alternative framework.

---

## Learning Objectives

- Understand relational database concepts and terminology.
- Write SQL queries for creating, reading, updating, and deleting data.
- Use SQLite for local development and understand PostgreSQL for production.
- Design database schemas with proper relationships and constraints.
- Integrate Python applications with databases using sqlite3 and SQLAlchemy.
- Build REST API endpoints with FastAPI.
- Implement basic authentication and request validation.

---

## Topics Covered

1. Introduction to relational databases
2. SQL fundamentals
3. SQLite
4. PostgreSQL
5. Database design and relationships
6. CRUD operations
7. Python database integration
8. SQLAlchemy and ORM fundamentals
9. FastAPI (primary) / Flask (alternative)
10. REST API development and authentication fundamentals

## Project Milestone: Student Management REST API

Build a REST API that:

- Provides endpoints for managing students, courses, and enrollments.
- Stores data in a SQLite database with proper schema design.
- Supports full CRUD operations through HTTP methods.
- Validates incoming request data.
- Returns structured JSON responses with appropriate status codes.
- Includes basic authentication for protected endpoints.
