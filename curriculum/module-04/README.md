# Module 04: Object-Oriented Programming

**Days 31--40 | Intermediate**

---

## Overview

This module introduces object-oriented programming (OOP) in Python. You will learn to model real-world entities as classes and objects, protect data with encapsulation, extend behavior through inheritance, and design flexible systems using polymorphism and abstraction.

This module integrates the existing [python-oop](../../python-oop/) curriculum, which contains comprehensive lectures, hands-on exercises, and a complete Student Management System reference implementation. The daily lessons here provide structured navigation through that material alongside additional practice.

---

## Learning Objectives

- Explain the difference between procedural and object-oriented programming.
- Define classes with attributes and methods.
- Use constructors (`__init__`) and the `self` parameter.
- Apply encapsulation to protect object state.
- Implement inheritance and use `super()` for method delegation.
- Write polymorphic code using duck typing and method overriding.
- Use abstract base classes to define contracts.
- Model relationships with composition.
- Apply SOLID design principles to real systems.

---

## Topics Covered

1. Procedural versus object-oriented programming
2. Classes and objects
3. Attributes and methods
4. Constructors and self
5. Encapsulation
6. Inheritance
7. Polymorphism
8. Abstraction
9. Composition
10. SOLID principles and basic system modeling

## Project Milestone: Student Management System

Build a Student Management System that:

- Models students, lecturers, courses, results, and attendance as classes.
- Uses inheritance to share common behavior between user types.
- Applies encapsulation to protect student records and grades.
- Implements polymorphism for different result processing strategies.
- Uses composition to build complex relationships between entities.
- Includes a command-line interface for managing student data.

See the complete reference implementation in [python-oop/projects/student-management-system/](../../python-oop/projects/student-management-system/).
