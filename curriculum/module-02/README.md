# Module 02: Data Structures and Problem Solving

**Days 11--20 | Beginner**

---

## Overview

This module introduces Python's built-in data structures and the loop constructs used to process them. You will learn to organize, search, filter, and transform collections of data. Exception handling ensures your programs respond gracefully to unexpected input.

---

## Learning Objectives

- Create, access, and modify lists, tuples, dictionaries, and sets.
- Use for loops and while loops to iterate over data.
- Write nested loops for multi-dimensional data processing.
- Build list comprehensions and dictionary comprehensions for concise data transformations.
- Test membership and iterate collections efficiently.
- Handle exceptions with try/except to write robust programs.
- Decompose problems into smaller, solvable steps.

---

## Topics Covered

1. Lists
2. Tuples
3. Dictionaries
4. Sets
5. Loops (for and while)
6. Nested loops
7. List and dictionary comprehensions
8. Membership and iteration
9. Exception handling
10. Problem decomposition and basic algorithmic thinking

## Project Milestone: Student Result Processing System

- Stores student names and their scores across multiple subjects in dictionaries.
- Calculates individual and class averages.
- Determines pass/fail status based on configurable thresholds.
- Generates a formatted results report.
- Handles invalid input gracefully with exception handling.
