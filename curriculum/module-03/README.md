# Module 03: Functions, Modules and File Handling

**Days 21--30 | Beginner to Intermediate**

---

## Overview

This module teaches you to organize code into reusable functions and modules, and to read from and write to files. You will learn to structure programs for maintainability, work with external data formats, and manage project dependencies with virtual environments.

---

## Learning Objectives

- Define functions with parameters and return values.
- Understand variable scope (local, global, enclosing).
- Use positional, keyword, and default arguments effectively.
- Write lambda functions for simple transformations.
- Import and create Python modules and packages.
- Read and write text files, CSV files, and JSON data.
- Set up virtual environments and manage dependencies with pip.

---

## Topics Covered

1. Defining and calling functions
2. Parameters and return values
3. Positional and keyword arguments
4. Default arguments
5. Variable scope
6. Lambda functions
7. Modules and packages
8. Reading and writing files
9. CSV and JSON
10. Virtual environments and dependency management

## Project Milestone: Personal Expense Tracker

Build a command-line expense tracker that:

- Records expenses with date, category, amount, and description.
- Stores data persistently in a CSV or JSON file.
- Provides summary reports (total by category, monthly totals).
- Uses functions to organize logic cleanly.
- Loads and saves data between sessions.
