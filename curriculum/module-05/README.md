# Module 05: Automation and Web Scraping

**Days 41--50 | Intermediate**

---

## Overview

This module teaches you to automate repetitive tasks and extract data from the web using Python. You will work with the filesystem, send HTTP requests, parse HTML, and build automated workflows. Responsible scraping practices are emphasized throughout.

---

## Learning Objectives

- Navigate and manipulate the filesystem with os and pathlib.
- Use regular expressions to find and transform text patterns.
- Send HTTP requests and process API responses.
- Parse HTML with Beautiful Soup to extract structured data.
- Automate browser interactions with Selenium.
- Send emails programmatically.
- Schedule and orchestrate automation workflows.

---

## Topics Covered

1. Python standard library for automation
2. os and pathlib
3. Working with files and directories
4. Regular expressions
5. HTTP requests
6. APIs and JSON responses
7. Beautiful Soup
8. Selenium fundamentals
9. Email automation
10. Task scheduling and automation workflows

## Project Milestone: Automated Web Research Assistant

Build an application that:

- Accepts a research topic from the user.
- Searches publicly accessible web sources for relevant information.
- Extracts and organizes key data points.
- Generates a structured research summary.
- Saves results to a file for later reference.

**Ethical guidelines:** Respect website terms of service, rate limits, robots.txt, and user privacy. Do not build tools that automate spam, bypass access controls, or scrape personal data without consent.
