# Module 09: Software Engineering Practices

**Days 81--90 | Intermediate to Advanced**

---

## Overview

This module focuses on the engineering practices that separate scripts from production-quality software. You will learn to write clean code, test your programs, manage version control workflows, document your work, and deploy applications using containers and CI/CD pipelines.

---

## Learning Objectives

- Write clean, readable, and maintainable Python following PEP 8.
- Apply systematic debugging techniques to diagnose issues.
- Write unit tests with unittest and pytest.
- Use logging to instrument applications for observability.
- Manage collaborative Git workflows with branches and pull requests.
- Write effective documentation for code and projects.
- Containerize applications with Docker and set up basic CI/CD.

---

## Topics Covered

1. Writing clean and maintainable Python
2. PEP 8 and code quality tools
3. Debugging techniques
4. Unit testing with unittest and pytest
5. Integration testing fundamentals
6. Logging
7. Git and GitHub workflows
8. Branches and pull requests
9. Documentation
10. Docker, CI/CD, and deployment fundamentals

## Project Milestone: Build, Test, Document, and Deploy a Python Application

Take a project from earlier in the curriculum and apply professional engineering practices:

- Refactor it to follow PEP 8 and clean code principles.
- Add a comprehensive test suite with unittest or pytest.
- Add logging for key operations and error conditions.
- Write a README with setup instructions, usage, and architecture overview.
- Containerize the application with Docker.
- Set up a GitHub Actions workflow for automated testing.
