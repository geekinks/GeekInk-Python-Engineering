# Module 10: AI, Machine Learning, and Capstone

**Days 91--100 | Advanced**

---

## Overview

This final module introduces machine learning and AI-powered application development. You will learn fundamental ML concepts, train and evaluate models with scikit-learn, integrate AI APIs, and build a capstone project that demonstrates everything you have learned across the 100-day program.

---

## Learning Objectives

- Understand the distinction between supervised and unsupervised learning.
- Prepare datasets for machine learning (feature selection, train/test splits, scaling).
- Train and evaluate classification and regression models with scikit-learn.
- Interpret model performance metrics (accuracy, precision, recall, F1).
- Integrate AI APIs into Python applications.
- Apply responsible AI principles including fairness, transparency, and data privacy.
- Design, build, and present a complete capstone project.

---

## Topics Covered

1. Introduction to machine learning
2. Supervised and unsupervised learning
3. Scikit-learn
4. Data preparation for ML
5. Model training
6. Model evaluation
7. AI APIs and integration
8. Responsible AI and data privacy
9. Building AI-powered applications
10. Final project presentation and technical defense

## Project Milestone: AI-Powered Solution for a Real-World Problem

Design, build, and present a capstone project that:

- Addresses a real-world problem relevant to your community or industry.
- Uses machine learning or AI APIs as a core component.
- Incorporates skills from across the entire 100-day program (data handling, OOP, APIs, testing, documentation).
- Includes a trained model or integrated AI service with measurable performance.
- Follows responsible AI practices.
- Is presented in a technical defense with architecture explanation, live demonstration, and Q&A.

See [Capstone Guidelines](../../docs/capstone-guidelines.md) for full requirements and evaluation criteria.
