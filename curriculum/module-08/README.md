# Module 08: Data Science and Visualization

**Days 71--80 | Intermediate to Advanced**

---

## Overview

This module introduces data science with Python. You will learn to load, clean, transform, and analyze datasets using industry-standard libraries, and present findings through static and interactive visualizations.

---

## Learning Objectives

- Set up and use Jupyter Notebook for interactive data analysis.
- Perform numerical computations with NumPy arrays.
- Load, explore, clean, and transform data with Pandas.
- Handle missing data, duplicates, and inconsistent formatting.
- Create publication-quality static charts with Matplotlib and Seaborn.
- Build interactive visualizations and dashboards with Plotly.
- Communicate data-driven insights effectively.

---

## Topics Covered

1. Introduction to data science
2. Jupyter Notebook
3. NumPy
4. Pandas fundamentals
5. Data cleaning
6. Data transformation
7. Data analysis
8. Matplotlib
9. Seaborn
10. Plotly and interactive dashboards

## Project Milestone: Northern Nigeria Data Analysis Dashboard

Build a data analysis project that:

- Uses a relevant, ethically sourced dataset about Northern Nigeria (education, agriculture, health, or economics).
- Cleans and prepares the raw data for analysis.
- Performs exploratory data analysis to identify patterns and trends.
- Creates at least five different chart types to present findings.
- Builds an interactive dashboard using Plotly or a similar tool.
- Documents findings, methodology, and conclusions in a written report.
