# GeekInk Python Engineering — 100-Day Curriculum

**100 Days. 100 Challenges. Real Engineering.**

This curriculum takes you from zero Python experience to building real-world applications across ten structured modules. Each module spans ten days and culminates in a hands-on project milestone.

---

## Program Structure

The 100-day program is divided into ten modules of increasing complexity. Early modules establish core programming fundamentals. Middle modules introduce professional tools and frameworks. Later modules tackle engineering practices, data science, and machine learning.

Every day follows a consistent format: learning objectives, concept explanations, practical examples, guided practice, a daily challenge, and a reflection prompt. See the [Student Guide](../docs/student-guide.md) for details on how to work through lessons and submit assignments.

## Learning Progression

The curriculum is designed as a progressive ladder:

1. **Foundation (Modules 1--3):** Core Python syntax, data structures, functions, and file handling. You build confidence writing Python programs from scratch.

2. **Architecture (Modules 4--5):** Object-oriented design and automation. You learn to model real-world systems and automate repetitive tasks.

3. **Full-Stack (Modules 6--7):** Databases, APIs, and desktop applications. You build complete applications with persistent storage and user interfaces.

4. **Data and Intelligence (Modules 8--10):** Data science, software engineering best practices, and machine learning. You analyze data, write production-quality code, and build AI-powered solutions.

Each module builds directly on the skills from previous modules. Skipping modules is not recommended for beginners.

## How to Navigate

1. Start with [Module 01](module-01/README.md) and work through each day sequentially.
2. Each day's directory contains a `README.md` with the full lesson.
3. Complete the daily challenge before moving to the next day.
4. At the end of each module, build the project milestone.
5. Submit your work following the instructions in [CONTRIBUTING.md](../CONTRIBUTING.md).
6. Use the [Student Guide](../docs/student-guide.md) for environment setup and workflow details.
