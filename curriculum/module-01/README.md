# Module 01: Python Foundations

**Days 1--10 | Beginner**

---

## Overview

This module introduces Python as a programming language and establishes the fundamental skills every programmer needs. By the end of these ten days, you will be able to write Python programs that accept user input, perform calculations, make decisions with conditional logic, and produce formatted output.

---

## Learning Objectives

- Install Python and configure a development environment.
- Understand Python syntax, execution flow, and the interactive interpreter.
- Declare variables and work with core data types (int, float, str, bool).
- Perform arithmetic, comparison, and logical operations.
- Manipulate strings using indexing, slicing, and built-in methods.
- Read user input and produce formatted output.
- Write conditional statements to control program flow.
- Apply basic debugging techniques to identify and fix errors.

---

## Topics Covered

1. Introduction to Python and programming
2. Installing Python and configuring the development environment
3. Python syntax and execution
4. Variables and naming conventions
5. Data types
6. Type conversion
7. Arithmetic and comparison operators
8. Strings and string manipulation
9. User input and output
10. Conditional statements
11. Debugging and basic problem-solving

## Project Milestone: Smart Personal Profile and Calculator

Build an interactive command-line application that:

- Collects personal information from the user (name, age, interests).
- Performs calculations based on user input (BMI calculator, age-in-days converter, savings projector).
- Uses conditional logic to provide personalized feedback.
- Displays a formatted profile summary.

This project integrates every concept from the module: variables, data types, type conversion, operators, strings, input/output, and conditionals.
