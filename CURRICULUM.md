# Curriculum

This is the canonical 60-session curriculum. Every linked week contains Monday through Friday lesson files, a weekly overview, exercises, an assignment brief, and resources.

| Week | Monday | Tuesday | Wednesday | Thursday | Friday |
|---|---|---|---|---|---|
| 1 | Python and setup | Syntax and values | Variables and operators | Input/output profile | Review and calculator |
| 2 | Decisions | Loops | Strings and lists | Collections grading feature | Demo and challenge |
| 3 | Functions | Arguments and scope | Comprehensions/modules | Exceptions and packages | Modular-system review |
| 4 | Text/files/pathlib | JSON and CSV | Dates, regex, standard library | Records feature | Dependency and data review |
| 5 | Classes/objects | Attributes and methods | Encapsulation/properties | Inheritance/composition | OOP demo and review |
| 6 | Clean code/Git | Debugging/logging/docs | pytest | Fixtures, mocks, quality | Refactor review |
| 7 | Data models/SQL | SQLite CRUD | Relationships/transactions | PostgreSQL/SQLAlchemy | Database project review |
| 8 | HTTP and REST | FastAPI routes | Pydantic validation | CRUD API | API demo and review |
| 9 | PostgreSQL integration | Migrations/config | Auth and roles | Middleware/security/tasks | Secure API review |
| 10 | Automation/files | CSV/Excel | CLI/API requests | Responsible scraping/scheduling | Automation demo |
| 11 | Async/concurrency | Performance/security | API tests/monitoring | Docker/deployment | Production-readiness review |
| 12 | Discovery and PRD | Architecture/design | Build sprint | Test/docs/deploy | Presentation and retrospective |
