# Advanced Projects

Projects for students in Modules 08--10 applying data science, engineering best practices, and machine learning.

---

## Project List

### Module 08: Northern Nigeria Data Analysis Dashboard
A data analysis project using ethically sourced datasets about Northern Nigeria, performing exploratory analysis, creating multiple chart types, and building an interactive Plotly dashboard with a written report.

- **Skills:** Pandas, NumPy, Matplotlib, Seaborn, Plotly, data cleaning, EDA
- **Curriculum link:** [Module 08](../../curriculum/module-08/README.md)

### Module 09: Build, Test, Document, and Deploy a Python Application
Take an earlier project, refactor it to PEP 8, add a test suite with pytest, add logging, write documentation, containerize with Docker, and set up CI/CD with GitHub Actions.

- **Skills:** PEP 8, pytest, logging, Git workflows, Docker, CI/CD
- **Curriculum link:** [Module 09](../../curriculum/module-09/README.md)

### Module 10: AI-Powered Solution for a Real-World Problem
A capstone project addressing a real-world problem using machine learning or AI APIs, incorporating skills from the entire program, with a technical defense presentation.

- **Skills:** scikit-learn, AI APIs, responsible AI, full-stack integration
- **Curriculum link:** [Module 10](../../curriculum/module-10/README.md)
- **Capstone guidelines:** [docs/capstone-guidelines.md](../../docs/capstone-guidelines.md)
