# Beginner Projects

Projects suitable for students in Modules 01--03 who are building foundational Python skills.

---

## Project List

### Module 01: Smart Personal Profile and Calculator
An interactive command-line application that collects personal information, performs calculations, uses conditional logic for personalized feedback, and displays a formatted summary.

- **Skills:** Variables, data types, operators, strings, input/output, conditionals
- **Curriculum link:** [Module 01](../../curriculum/module-01/README.md)

### Module 02: Student Result Processing System
A command-line application that stores student scores, calculates averages, determines pass/fail status, generates formatted reports, and handles invalid input.

- **Skills:** Lists, dictionaries, loops, comprehensions, exception handling
- **Curriculum link:** [Module 02](../../curriculum/module-02/README.md)

### Module 03: Personal Expense Tracker
A command-line expense tracker that records expenses, stores data in CSV or JSON, provides summary reports by category and time period, and persists data between sessions.

- **Skills:** Functions, file I/O, CSV/JSON, modules
- **Curriculum link:** [Module 03](../../curriculum/module-03/README.md)
