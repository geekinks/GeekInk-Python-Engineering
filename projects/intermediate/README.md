# Intermediate Projects

Projects for students in Modules 04--07 who are building full applications with OOP, databases, APIs, and GUIs.

---

## Project List

### Module 04: Student Management System
A system modeling students, lecturers, courses, results, and attendance using OOP principles including inheritance, encapsulation, polymorphism, and composition.

- **Skills:** Classes, objects, OOP design, SOLID principles
- **Curriculum link:** [Module 04](../../curriculum/module-04/README.md)
- **Reference implementation:** [python-oop/projects/student-management-system/](../../python-oop/projects/student-management-system/)

### Module 05: Automated Web Research Assistant
An application that accepts a research topic, searches public web sources, extracts and organizes data, generates a structured summary, and saves results.

- **Skills:** HTTP requests, APIs, Beautiful Soup, Selenium, file automation
- **Curriculum link:** [Module 05](../../curriculum/module-05/README.md)

### Module 06: Student Management REST API
A REST API built with FastAPI providing endpoints for managing students, courses, and enrollments with a SQLite backend, request validation, and basic authentication.

- **Skills:** SQL, SQLite, SQLAlchemy, FastAPI, REST API design
- **Curriculum link:** [Module 06](../../curriculum/module-06/README.md)

### Module 07: Desktop Inventory Management Application
A Tkinter desktop application for managing inventory with add/edit/delete/search functionality, SQLite storage, input validation, and a sortable table view.

- **Skills:** Tkinter, event-driven programming, database integration, packaging
- **Curriculum link:** [Module 07](../../curriculum/module-07/README.md)
