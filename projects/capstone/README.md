# Capstone: GeekInk Learning Management Backend

Suggested features: student registration, authentication, role-based access, course and lesson management, enrolment, assignments, progress tracking, assessment management, database integration, REST API, documentation, and deployment.

Students may choose another education, agriculture, business, healthcare, or community-development problem if it meets [the project guidelines](../../docs/project-guidelines.md). Required artefacts are defined in [Week 12](../../weeks/week-12-capstone/) and [the capstone rubric](../../assessments/capstone-rubric.md).
