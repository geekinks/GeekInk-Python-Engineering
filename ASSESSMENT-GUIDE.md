# Assessment Guide

| Evidence | Weight |
|---|---:|
| Conceptual understanding | 15% |
| Practical coding exercises | 20% |
| Weekly assignment | 20% |
| GitHub contributions and documentation | 10% |
| Weekly mini-project | 20% |
| Participation and code review | 5% |
| Final capstone | 10% |

Use the [weekly template](assessments/weekly-assessments/weekly-assessment-template.md) for formative feedback. Evaluate whether code works, is readable, handles likely errors, and can be explained by its author.
