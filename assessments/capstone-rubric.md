# Capstone Assessment Rubric

| Criterion | Weight | Evidence |
|---|---:|---|
| Problem definition, PRD, SRS, personas | 15% | Clear user need and scoped requirements |
| Architecture, data model, API design | 15% | Diagrams/specifications match implementation |
| Functional implementation | 25% | Core user journey works |
| Tests, reliability, and security | 15% | Automated/manual evidence and review |
| Documentation and deployment | 15% | Reproducible setup, operating notes, deployed or reproducible local delivery |
| Demonstration and reflection | 15% | Clear technical presentation and trade-offs |

Minimum submission includes a problem statement, proposal, PRD, SRS, persona and journey, architecture, database schema, API specification, source, tests, documentation, deployment evidence, and technical demonstration.
