- [Python Official Documentation](https://docs.python.org/3/) — The definitive reference for the Python language and standard library.
- [Python Tutorial](https://docs.python.org/3/tutorial/) — The official beginner tutorial from the Python documentation.
- [PEP 8 Style Guide](https://peps.python.org/pep-0008/) — The standard style guide for Python code.
- [Python Module Index](https://docs.python.org/3/py-modindex.html) — Index of all standard library modules.

## How to Use These Resources

- **Do not try to read everything.** Use these resources to supplement specific topics as you encounter them in the curriculum.
- **Start with the official documentation.** It is the most accurate and up-to-date source.
- **Practice platforms are for reinforcement.** After completing a day's lesson, try related problems on HackerRank or Exercism.
- **Read code, not just tutorials.** Study solutions, open-source projects, and community notebooks to learn patterns.
- **Bookmark, do not hoard.** Save links for topics you will need later. Come back when the curriculum reaches that module.
