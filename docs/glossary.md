# Glossary

- **API:** an interface through which software communicates.
- **CRUD:** create, read, update, and delete operations.
- **Endpoint:** a URL and HTTP method exposed by an API.
- **ORM:** a tool that maps database rows to Python objects.
- **Virtual environment:** isolated Python packages for one project.
- **Test fixture:** repeatable setup used by a test.
- **Migration:** versioned database schema change.
- **JWT:** signed token commonly used for API authentication.
