# Assessment Rubric

This compatibility page points to the active [Assessment Guide](../ASSESSMENT-GUIDE.md) and [capstone rubric](../assessments/capstone-rubric.md).

Weekly evaluation assesses conceptual understanding (15%), practical exercises (20%), assignment (20%), GitHub/documentation (10%), mini-project (20%), and participation/code review (5%). The capstone contributes 10% of the programme result.
