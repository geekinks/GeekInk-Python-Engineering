# Capstone Guidelines

The capstone is Week 12 of the active 12-week programme. Build a practical Python solution for education, agriculture, business, healthcare, or community development.

Submit a problem statement, proposal, PRD, SRS, personas and user journey, architecture, data schema, API specification where applicable, source code, tests, security review, deployment evidence, README, and technical demonstration. Start with a small usable slice; additional features must not replace reliability, documentation, or tests.

Use [Week 12](../weeks/week-12-capstone/), [project guidelines](project-guidelines.md), and [the capstone rubric](../assessments/capstone-rubric.md).
