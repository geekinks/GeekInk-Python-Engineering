# GeekInk Python Engineering

## A practical 12-week Python engineering programme

GeekInk Python Engineering is a beginner-friendly, project-based programme by GeekInk Innovations Ltd. Over **12 weeks**, students meet Monday to Friday for **60 structured learning sessions**. Saturday is optional revision, mentorship, and project completion; Sunday is rest and preparation.

## Start here

1. Read the [Student Guide](STUDENT-GUIDE.md).
2. Complete [environment setup](docs/python-environment-setup.md).
3. Review [ROADMAP.md](ROADMAP.md) and [CURRICULUM.md](CURRICULUM.md).
4. Begin [Week 1](weeks/week-01-python-foundations/).

## Learning approach

| Day | Approach |
|---|---|
| Monday | Concepts and foundations |
| Tuesday | Guided examples and deeper understanding |
| Wednesday | Hands-on implementation |
| Thursday | Feature or mini-project build |
| Friday | Assessment, review, demonstration, and reflection |

Students write code in every session, use Git and GitHub throughout, test locally before pushing, and document major projects.

## Requirements and assessment

Python 3.10+, Git, and VS Code or another text editor are sufficient for Weeks 1-6. Later weeks add packages inside a virtual environment. See [the environment guide](docs/python-environment-setup.md).

Weekly work is assessed through conceptual understanding (15%), practical exercises (20%), assignments (20%), GitHub/documentation (10%), mini-projects (20%), and participation/code review (5%). The final capstone contributes 10%. Read [the Assessment Guide](ASSESSMENT-GUIDE.md).
