# Week 02 Friday: Collections challenge and grading app review

## Learning objectives

- Explain iteration and  edge cases.
- Apply today's ideas in a small Python program.
- Inspect output and improve the program after a test run.

## Concepts students must understand

- iteration
- edge cases
- data modelling
- review

## Detailed lesson content

Demonstrate the grading application. Review empty input, scores outside 0-100, and duplicate names. Explain why your collection choice fits the problem.

Before coding, describe the input, processing, and output in ordinary language. Run the smallest possible version, then extend it one change at a time. Read the error message before asking for help.

## Code example

~~~python
scores = [55, 80, 90]
print(sum(scores) / len(scores))
~~~

## Practical coding activity

Calculate average, highest, and lowest score.

## Guided exercise

Peer-review a report for clear labels and invalid score handling.

## Independent exercise

Submit the student grading application.

## Expected output

A class report includes average and grades.

## Homework or assignment

Write a short README explaining how to run the app.
