# Week 02 Monday: Conditional decisions

## Learning objectives

- Explain if and  elif.
- Apply today's ideas in a small Python program.
- Inspect output and improve the program after a test run.

## Concepts students must understand

- if
- elif
- else
- comparison
- logical operators

## Detailed lesson content

Conditions let a program choose a path. State the rule in plain language first, then implement it. Combine conditions only when each part can be explained.

Before coding, describe the input, processing, and output in ordinary language. Run the smallest possible version, then extend it one change at a time. Read the error message before asking for help.

## Code example

~~~python
score = 72
if score >= 50:
    print('Pass')
else:
    print('Try again')
~~~

## Practical coding activity

Classify three scores using one threshold.

## Guided exercise

Add distinction, pass, and retry bands.

## Independent exercise

Write an admission eligibility checker.

## Expected output

A status message matches each input score.

## Homework or assignment

Document three comparison and logical operators.
