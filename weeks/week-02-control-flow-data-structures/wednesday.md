# Week 02 Wednesday: Strings and lists

## Learning objectives

- Explain indexing and  slicing.
- Apply today's ideas in a small Python program.
- Inspect output and improve the program after a test run.

## Concepts students must understand

- indexing
- slicing
- methods
- mutable list

## Detailed lesson content

Strings are ordered text; lists are ordered, changeable collections. Test a small example after each change rather than assuming list methods return a new list.

Before coding, describe the input, processing, and output in ordinary language. Run the smallest possible version, then extend it one change at a time. Read the error message before asking for help.

## Code example

~~~python
students = ['Ada', 'Bashir']
students.append('Chidi')
print(students[0])
~~~

## Practical coding activity

Add, remove, and display names from a class list.

## Guided exercise

Write a function-free script that counts words in a sentence.

## Independent exercise

Create a shopping list tool with add and view choices.

## Expected output

A changed list and selected item display.
