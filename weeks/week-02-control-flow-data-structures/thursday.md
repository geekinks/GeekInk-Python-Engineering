# Week 02 Thursday: Tuples, sets, dictionaries, and grading feature

## Learning objectives

- Explain tuple and  set.
- Apply today's ideas in a small Python program.
- Inspect output and improve the program after a test run.

## Concepts students must understand

- tuple
- set
- key-value pair
- membership

## Detailed lesson content

Choose a tuple for fixed information, a set for unique values, and a dictionary when values have names. Dictionaries make a result record easier to read than parallel lists.

Before coding, describe the input, processing, and output in ordinary language. Run the smallest possible version, then extend it one change at a time. Read the error message before asking for help.

## Code example

~~~python
result = {'name': 'Aisha', 'score': 84}
print(result['name'])
~~~

## Practical coding activity

Store three student records in dictionaries.

## Guided exercise

Use a set to remove duplicate course names.

## Independent exercise

Implement grade calculation and reporting for one student.

## Expected output

A labelled name, score, and grade print.

## Homework or assignment

Extend the grading app to record at least three students.
