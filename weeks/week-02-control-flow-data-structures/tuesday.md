# Week 02 Tuesday: Loops and safe repetition

## Learning objectives

- Explain for and  while.
- Apply today's ideas in a small Python program.
- Inspect output and improve the program after a test run.

## Concepts students must understand

- for
- while
- range
- break
- continue

## Detailed lesson content

Use a for loop when iterating over known items and a while loop while a condition remains true. Ensure every while loop can eventually stop.

Before coding, describe the input, processing, and output in ordinary language. Run the smallest possible version, then extend it one change at a time. Read the error message before asking for help.

## Code example

~~~python
for number in range(1, 4):
    print(number)
~~~

## Practical coding activity

Print numbers 1-10 and label even values.

## Guided exercise

Build a three-attempt password prompt with a safe exit.

## Independent exercise

Create a number guessing loop with a fixed secret.

## Expected output

The loop repeats the intended number of times.
