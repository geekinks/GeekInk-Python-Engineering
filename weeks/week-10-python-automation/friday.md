# Week 10 Friday: Automation demonstration

## Learning objectives

- Explain logging and  failure recovery.
- Apply today's ideas in a working implementation.
- Test normal and failure behaviour before sharing the result.

## Concepts students must understand

- logging
- failure recovery
- audit trail
- review

## Detailed lesson content

Demonstrate the automation on sample data. Review preview mode, validation, logs, recovery, and a human approval step for consequential actions such as email. Discuss email automation as a concept, not a place to store passwords.

Plan input, processing, output, and failure behaviour before coding. Make a small working version first; add complexity only after observing correct output.
