# Week 10: Python Automation and Practical Applications

## Weekly theme

Python Automation and Practical Applications advances the practical engineering skills needed for the capstone.

## Learning objectives

- Explain the core ideas and their real-world trade-offs.
- Implement and test a working feature.
- Document choices, limits, and safe operating practices.

Weeks 1-9

## Practical exercises

Complete guided and independent exercises in each lesson. Run code locally and record one edge case.

## Assignment

**Student attendance and report automation system.** Submit source, README, setup and run steps, evidence of testing, and reflection.

## Expected deliverables

- Runnable feature or project.
- Git history with focused commits.
- Documentation sufficient for a reviewer to reproduce the work.

## Assessment criteria

Conceptual understanding 15%, practical exercises 20%, assignment 20%, GitHub/documentation 10%, mini-project 20%, participation/code review 5%.
