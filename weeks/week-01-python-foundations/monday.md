# Week 01 Monday: Programming, Python, and local setup

## Learning objectives

- Explain what a program is and  Python use cases.
- Apply today's ideas in a small Python program.
- Inspect output and improve the program after a test run.

## Concepts students must understand

- what a program is
- Python use cases
- interpreter
- script

## Detailed lesson content

A program is a precise set of instructions. Python reads a script from top to bottom and is a useful first language because its syntax is readable. Verify the interpreter before writing code.

Before coding, describe the input, processing, and output in ordinary language. Run the smallest possible version, then extend it one change at a time. Read the error message before asking for help.

## Code example

~~~python
print('Hello, GeekInk!')
~~~

## Practical coding activity

Create hello.py, run it from a terminal, and change the greeting.
