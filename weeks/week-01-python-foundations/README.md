# Week 01: Introduction to Python and Programming Fundamentals

## Weekly theme

Introduction to Python and Programming Fundamentals develops the next step towards production-quality Python work.

## Learning objectives

- Explain and apply the week's core concepts.
- Build, test, and improve a small working feature.
- Document decisions and commit progress with Git.

## Prerequisites

None

## Monday-Friday schedule

| Day | Session |
|---|---|
| Monday | [Programming, Python, and local setup](monday.md) |
| Tuesday | [Syntax, indentation, and basic values](tuesday.md) |
| Wednesday | [Variables, conversion, and operators](wednesday.md) |
| Thursday | [Input, output, and formatted profile](thursday.md) |
| Friday | [Foundation review and calculator demonstration](friday.md) |

## Practical exercises

Complete the daily guided and independent exercises. Reuse relevant retained material where noted and keep your own code in a separate working folder.

## Assignment

**Personal information and introduction program.** Deliver source code, README, sample data or test evidence where relevant, and a short reflection.

## Expected deliverables

- A runnable project or feature.
- Clear setup and run instructions.
- Meaningful commits and a self-review.

## Assessment criteria

Conceptual understanding 15%, practical exercises 20%, assignment 20%, GitHub/documentation 10%, mini-project 20%, and participation/code review 5%.
