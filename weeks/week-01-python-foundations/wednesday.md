# Week 01 Wednesday: Variables, conversion, and operators

## Learning objectives

- Explain assignment and  naming.
- Apply today's ideas in a small Python program.
- Inspect output and improve the program after a test run.

## Concepts students must understand

- assignment
- naming
- int
- float
- arithmetic
- comparison

## Detailed lesson content

Variables label values so a program can reuse them. Input arrives as text, so convert only after deciding the expected type. Use meaningful names and spaces around operators.

Before coding, describe the input, processing, and output in ordinary language. Run the smallest possible version, then extend it one change at a time. Read the error message before asking for help.

## Code example

~~~python
monthly_saving = 2500
months = 6
print(monthly_saving * months)
~~~

## Practical coding activity

Calculate weekly savings from a monthly amount and print a clear sentence.

## Guided exercise

Add a comparison that reports whether savings meet a target.

## Independent exercise

Build a simple savings estimator with two inputs.

## Expected output

A numeric total and an understandable message appear.

Complete the variable and operator exercises.
