# Week 01 Tuesday: Syntax, indentation, and basic values

## Learning objectives

- Explain statements and  indentation.
- Apply today's ideas in a small Python program.
- Inspect output and improve the program after a test run.

## Concepts students must understand

- statements
- indentation
- strings
- integers
- floats
- booleans

## Detailed lesson content

Python uses indentation to group work. A value has a type, and quoting a number makes it text rather than a number. Read error messages from the last line upward.

Before coding, describe the input, processing, and output in ordinary language. Run the smallest possible version, then extend it one change at a time. Read the error message before asking for help.

## Code example

~~~python
age = 18
name = 'Amina'
print(name, age)
~~~

## Practical coding activity

Deliberately fix an indentation error and identify each value type with type().

## Guided exercise

Predict the result of three expressions before executing them.

## Independent exercise

Write values for a school name, fees, attendance rate, and open status.

## Expected output

The values and their types print correctly.
