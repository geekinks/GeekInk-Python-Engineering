# Week 12 Monday: Problem discovery, PRD, and SRS

## Learning objectives

- Explain problem statement and  persona.
- Apply today's ideas in a working implementation.
- Test normal and failure behaviour before sharing the result.

## Concepts students must understand

- problem statement
- persona
- PRD
- SRS
- scope

## Detailed lesson content

Choose a problem that is real, specific, and small enough to finish. A PRD explains user value; an SRS makes technical behaviour testable. Define what the project will not do.

Plan input, processing, output, and failure behaviour before coding. Make a small working version first; add complexity only after observing correct output.

## Code example

~~~python
problem = {'user': 'school coordinator', 'need': 'track submissions'}
print(problem['need'])
~~~

## Practical coding activity

Write three candidate problems and rank them by impact and feasibility.

## Guided exercise

Create one persona and a short user journey.

## Independent exercise

Draft a problem statement, PRD, and SRS outline.

## Expected output

A scoped problem and acceptance criteria are written.

Get instructor approval before expanding scope.
