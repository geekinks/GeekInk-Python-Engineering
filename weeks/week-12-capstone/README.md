# Week 12: Capstone Project and Production Readiness

## Weekly theme

Capstone Project and Production Readiness advances the practical engineering skills needed for the capstone.

## Learning objectives

- Explain the core ideas and their real-world trade-offs.
- Implement and test a working feature.
- Document choices, limits, and safe operating practices.

## Prerequisites

Weeks 1-11

## Monday-Friday schedule

| Day | Session |
|---|---|
| Monday | [Problem discovery, PRD, and SRS](monday.md) |
| Tuesday | [Architecture, schema, and API design](tuesday.md) |
| Wednesday | [Implementation sprint](wednesday.md) |
| Thursday | [Testing, documentation, security, and deployment](thursday.md) |
| Friday | [Technical demonstration and retrospective](friday.md) |

## Practical exercises

Complete guided and independent exercises in each lesson. Run code locally and record one edge case.

## Assignment

**Production-ready Python application for a real community problem.** Submit source, README, setup and run steps, evidence of testing, and reflection.

## Expected deliverables

- Runnable feature or project.
- Git history with focused commits.
- Documentation sufficient for a reviewer to reproduce the work.

## Assessment criteria

Conceptual understanding 15%, practical exercises 20%, assignment 20%, GitHub/documentation 10%, mini-project 20%, participation/code review 5%.
