# Week 12 Friday: Technical demonstration and retrospective

## Learning objectives

- Explain presentation and  evidence.
- Apply today's ideas in a working implementation.
- Test normal and failure behaviour before sharing the result.

## Concepts students must understand

- presentation
- evidence
- feedback
- retrospective

## Detailed lesson content

Present the problem, user, design, working solution, test evidence, security decisions, and deployment. Explain trade-offs honestly. A retrospective turns completed work into the next improvement plan.

Plan input, processing, output, and failure behaviour before coding. Make a small working version first; add complexity only after observing correct output.

## Code example

~~~python
print('Demo: problem, solution, evidence, next step')
~~~

## Practical coding activity

Practise a timed demonstration with a peer.
