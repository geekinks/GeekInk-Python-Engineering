# Specialization: Data Science

**Advanced Track**

---

## Overview

This specialization extends Module 08 with deeper statistical analysis, advanced visualization techniques, and real-world data science project workflows. It prepares students for data analyst and data scientist roles.

---

## Prerequisites

- Modules 01--08: Python Foundations through Data Science and Visualization

---

## Learning Objectives

- Apply statistical methods to analyze and interpret datasets.
- Build advanced visualizations for complex data relationships.
- Perform hypothesis testing and statistical inference.
- Work with time series data and geospatial data.
- Build reproducible data analysis pipelines.
- Communicate findings through data storytelling.
