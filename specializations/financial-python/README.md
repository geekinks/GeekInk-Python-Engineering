# Specialization: Financial Python

**Advanced Track | Building on Core Foundations**

---

## Overview

This specialization teaches Python as a practical tool for financial analysis, reporting, forecasting, and portfolio modeling. It is designed for students who have completed the core Python foundations (Modules 01--03) and want to apply their skills in the finance domain.

The original 3-week Financial Python curriculum developed for GeekInk is preserved here and serves as the foundation for this track.

---

## Prerequisites

- Module 01: Python Foundations
- Module 02: Data Structures and Problem Solving
- Module 03: Functions, Modules and File Handling

Recommended:
- Module 08: Data Science and Visualization

## Learning Objectives

- Apply Python fundamentals to financial calculations (ROI, interest, profit margins).
- Load, clean, and analyze financial datasets with Pandas.
- Calculate moving averages, daily returns, and volatility metrics.
- Visualize stock prices and financial trends with Matplotlib and mplfinance.
- Build time series forecasting models.
- Perform portfolio analysis using correlation matrices and risk/return metrics.
- Develop a financial analysis capstone project.

---

## Curriculum Outline

### Week 1: Core Python for Finance
- Variables, data types, lists, dictionaries, loops, functions
- Reading and writing CSV files
- Financial calculations: profit, ROI, compound interest

### Week 2: Data Analysis and Visualization
- Pandas fundamentals and data cleaning
- Stock price analysis and moving averages
- Daily returns and volatility
- Matplotlib and mplfinance charting

### Week 3: Forecasting and Portfolio Modeling
- Time series forecasting and linear regression
- Correlation matrices and risk/return analysis
- Sharpe ratio and portfolio optimization
- Capstone project development
