# Specialization: Machine Learning

**Advanced Track**

---

## Overview

This specialization extends Module 10 with deeper coverage of machine learning algorithms, model tuning, natural language processing, computer vision fundamentals, and deploying ML models as services.

---

## Prerequisites

- Modules 01--10: Full 100-day core curriculum
- Specialization: Data Science (recommended)

---

## Learning Objectives

- Understand and implement a range of supervised and unsupervised algorithms.
- Perform feature engineering and model selection.
- Tune hyperparameters and prevent overfitting.
- Apply natural language processing techniques to text data.
- Work with image data for basic computer vision tasks.
- Deploy machine learning models as API services.
