# Instructor Guide

Teach the active 12-week sequence in [weeks/](weeks/), not the retained legacy daily curriculum. Each weekday session includes an explanation, live example, guided task, independent practice, expected output, homework, and resources.

Begin with a concrete problem, let students attempt it, then demonstrate a small solution. Reserve at least half of each session for code-writing, debugging, and feedback. Friday should include a short knowledge check, code review, demonstration, and reflection.

For low-connectivity cohorts, distribute the repository and required packages before the week, favour standard-library tasks, and run local demonstrations. Use Saturday for targeted remediation and project completion rather than introducing required new concepts.
