# 12-Week Roadmap

The programme runs for three months: twelve Monday-Friday learning weeks, with optional Saturday support and a Sunday rest day.

| Weeks | Stage | Evidence of learning |
|---|---|---|
| 1-2 | Foundations | Interactive scripts, structured data, and a grading app |
| 3-4 | Reusable programs and data files | Modular code and persistent student records |
| 5-6 | Engineering practice | OOP design, Git workflow, tests, documentation |
| 7-9 | Data and backend systems | Relational data, FastAPI, secure API features |
| 10-11 | Automation and delivery | Automation tool, asynchronous awareness, Docker image |
| 12 | Independent capstone | Documented, tested, demonstrated solution |

The active sequence is deliberately fundamentals-first: data structures and functions precede OOP; databases precede advanced backend work; security, testing, and deployment are reinforced before the capstone.
