# Datasets

Sample datasets for use in curriculum exercises and projects.

## Available Datasets

Datasets will be added as the curriculum develops. Students are encouraged to find and use publicly available datasets relevant to their projects.

## Recommended Public Data Sources

- Nigeria National Bureau of Statistics: https://nigerianstat.gov.ng
- World Bank Open Data: https://data.worldbank.org
- Kaggle Datasets: https://www.kaggle.com/datasets
- UCI Machine Learning Repository: https://archive.ics.uci.edu
- Our World in Data: https://ourworldindata.org

## Guidelines

- Use only ethically sourced, publicly available data.
- Credit the data source in your project documentation.
- Do not include personally identifiable information in submissions.
- Keep dataset files small enough for version control (under 10 MB).
