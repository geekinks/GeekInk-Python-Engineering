# Recommended Reading

Curated resources to supplement the GeekInk Python Engineering curriculum.

## Books (Free and Open)

- **Automate the Boring Stuff with Python** by Al Sweigart -- Free to read online. Excellent for practical Python automation.
- **Think Python** by Allen B. Downey -- Free PDF. Clear introduction to programming concepts.
- **Python Crash Course** by Eric Matthes -- Companion resources available free online.

## Official Documentation

- Python Official Tutorial: https://docs.python.org/3/tutorial/
- Python Standard Library: https://docs.python.org/3/library/
- PEP 8 Style Guide: https://peps.python.org/pep-0008/

## Online Practice

- HackerRank Python Track: https://www.hackerrank.com/domains/python
- LeetCode: https://leetcode.com
- Exercism Python Track: https://exercism.org/tracks/python
- Project Euler: https://projecteuler.net

## Video Resources

- MIT OpenCourseWare: Introduction to Computer Science and Programming Using Python
- freeCodeCamp Python tutorials on YouTube
