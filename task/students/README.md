# Student Submissions

This directory contains student work organized by GitHub username.

---

## Directory Structure

Each student creates a folder named after their GitHub username:

```
task/students/your-github-username/
    README.md
    module-01/
        day-001/
            solution.py
        day-002/
            solution.py
        ...
    module-02/
        day-011/
            solution.py
        ...
    projects/
        module-01-project/
            README.md
            main.py
            ...
```

---

## Getting Started

1. Fork the repository to your GitHub account.
2. Clone your fork to your local machine.
3. Create your personal directory: `task/students/your-github-username/`
4. Add a `README.md` with your name and cohort.
5. Create module and day subdirectories as you progress.
6. Commit your work regularly with meaningful commit messages.
7. Push to your fork and open a pull request when ready for review.

---

## What to Submit

- Daily challenge solutions (`.py` files).
- Module project milestone code and documentation.
- A brief reflection in each day's directory or in your personal README.

---

## What NOT to Submit

- Virtual environment directories (`venv/`, `.venv/`).
- `__pycache__/` or `.pyc` files.
- Environment files (`.env`) or secrets.
- IDE configuration folders (`.vscode/`, `.idea/`).
- Large binary files or datasets (link to them instead).

---

## Submission Template

Copy this into `task/students/your-github-username/README.md`:

```markdown
# [Your Name]

**GitHub:** [your-github-username](https://github.com/your-github-username)
**Cohort:** [Cohort number]
**Start Date:** [YYYY-MM-DD]

## Progress

| Module | Status |
| :--- | :--- |
| Module 01: Python Foundations | In Progress / Complete |
| Module 02: Data Structures | Not Started |
| ... | ... |
```

---

## Pull Request Guidelines

- Title your PR: `[Module XX] Day XXX - Your Name`
- Include a brief description of what you completed.
- Reference the day or module number.
- Request a review from your instructor or a peer.

See [CONTRIBUTING.md](../../CONTRIBUTING.md) for full contribution guidelines.
